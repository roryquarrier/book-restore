YOUR TASKS:

1. CREATE ~/book-bash/worker/worker.py
   The main worker loop:
   a. Connect to Supabase using service role key (from ~/book-bash/.env)
   b. Poll the jobs table every 5 seconds for status='uploaded' jobs
   c. For each job found:
      - Claim it: UPDATE jobs SET status='extracting', updated_at=now() WHERE id=? AND status='uploaded' (atomic claim, prevents double-processing)
      - Download the source PDF from Supabase Storage to a local temp dir (/tmp/book-bash-jobs/{job_id}/)
      - Count pages (use pdf2image or PyPDF2 — whatever is available in ~/book-restorer/.venv)
      - Enforce 80-page hard cap. If >80 pages, mark job as 'failed' with error message, skip
      - Calculate cost: page_count * 3 credits
      - Call hold_credits(job_id, cost) via Supabase RPC. If hold fails (insufficient credits), mark job failed
      - Update job: status='regen_running', page_count=N, updated_at=now()
      - Start a heartbeat thread: UPDATE jobs SET updated_at=now() WHERE id=? every 30 seconds
      - Call restore.py: subprocess python ~/book-restorer/restore.py <pdf_path> --output /tmp/book-bash-jobs/{job_id}/output --provider openai --quality medium
      - Pass OPENAI_API_KEY from ~/book-restorer/.env
      - Wait for restore.py to complete (30-min max timeout)
      - On success:
        * Upload the restored PDF to Supabase Storage: book-bash/{user_id}/{timestamp}_restored.pdf
        * Update job: output_storage_path, status='complete' (or call commit_credits)
        * Call commit_credits(job_id, cost) via Supabase RPC
        * Stop heartbeat
        * Clean up local temp dir
      - On failure:
        * Call refund_credits(job_id, cost) via Supabase RPC
        * Update job: status='failed', error_message=<the error>
        * Stop heartbeat
        * Log the error
   d. Dead-man switch: if updated_at > 5 minutes stale on a 'regen_running' job, another worker can claim it (reset status to 'uploaded')
   e. Graceful shutdown on SIGTERM/SIGINT (stop heartbeat, finish current job, exit)
